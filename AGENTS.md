## 🎨 Mandatory UI Design System & Aesthetics (VIP / Luxury)

For ANY user interface changes or new pages in this repository:
- **Strictly read and follow** [`UI_DESIGN_GUIDE.md`](file:///c:/Users/MSI-BRAVO/OneDrive/M%C3%A1y%20t%C3%ADnh/New%20folder/UI_DESIGN_GUIDE.md).
- **Style**: Dark luxury, multi-layer glassmorphism (`backdrop-filter: blur(24px)`), animated aurora glows, vibrant neon accents (Emerald `#10b981`, Sapphire `#3b82f6`, Amber `#f59e0b`).
- **Icons**: Never use generic / primitive icons (e.g. basic padlock icon). Use custom layered SVG emblems with glowing rings, orbital motifs, and brand monograms.
- **Buttons**: Never use flat plain buttons. Use gradient backgrounds, shimmer light sweep effects on hover, and neon drop-shadow glows.
- **Typography**: Primary font is `Plus Jakarta Sans` (`--font-sans`), monospace / numbers / OTP / prices is `JetBrains Mono` (`--font-mono`).
- **Notifications**: Floating glass toasts with glowing left accent borders and entrance animations, never plain alert boxes.
